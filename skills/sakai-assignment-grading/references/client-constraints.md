# Capability constraints

Discover the tools actually available. The local catalog has thirteen optional grading tools, including source reads, export/resource access, prepare_assignment_grade_payload, save_assignment_grades, release_assignment_grades and receipt/readback tools. prepare_assignment_mcq_grades is removed; get_assignment_grading_proposal and report resources remain read-only compatibility access for existing records. Default V1 remains five tools, with three independently gated setup tools. Do not change flags, deploy or start compute to use this Skill.

Current migrated writes support one current submitted individual at a time, integral displayed points, English native forms and no Gradebook link. Broad input schemas do not establish bulk/decimal support. Anonymous/group grading, group Gradebooks, linked Gradebook writes, unsupported rubric/peer/content-review modes and historical attempts are not accepted. Context may conservatively report unsupported writes; investigate capability limits without bypassing them. Restricted or incomplete listings are not course totals.

Use the host's existing authenticated MCP connection. Current attachments cannot be read by this adapter; actual delegated attachment access previously failed before reaching the downstream servlet. Inline resources and external captures have narrower local proofs. Missing permission/hash/content is not an empty submission. SDK resource roundtrips do not establish host filesystem delivery, extraction accuracy or real-role acceptance. See workspace.md before choosing local processing.

External captures and operation journals require configured private conditional storage. Existing exports/proposals retain their expiry and actor/course/assignment binding. Do not assume native Sakai storage or the historical submission version column provides migrated write guarantees. Revisions are observations, not native compare-and-swap; there is no atomic multi-request or multi-row transaction. Journal send intents suppress automatic replay, but do not prove native write causation or exactly-once notifications. Unknown/partial stages require human reconciliation.

The tool-only native tree lacks the separately developed authentication integration required for its existing HTTP routes and flow protocol. Intended-host file delivery, delegated route/filter reach, real roles, concurrent-user isolation and end-to-end attachment integrity remain acceptance gates. Local changes are not a deployment or feature activation.
